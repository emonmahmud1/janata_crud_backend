# 🛠️ Janata WiFi - Backend (Node.js + Express + MongoDB)

This is the **backend** for Janata WiFi, handling trade data storage, updates, and retrieval using **Express.js** and **MongoDB**.

---

## 🚀 Features
- 📡 **REST API** for Trade Data Management  
- 🛢️ **MongoDB Database** 
- 🔄 **CORS Support** for Secure API Calls   
- ☁️ **Cloud Deployment** Ready  

---

## 🛠 Tech Stack
- 🟢 **Node.js** (Runtime)
- 🚀 **Express.js** (Backend Framework)
- 🗃️ **MongoDB** (Database)
- 🌍 **CORS** (Cross-Origin Resource Sharing)
- 📦 **Dotenv** (Environment Variables)

---

## 📦 Installation

### 1️⃣ Clone the Repository
```sh
https://github.com/emonmahmud1/janata_crud_backend.git
```

### 2️⃣ Install Dependencies
```sh
npm install
```

### 3️⃣ Configure Environment Variables  
Create a `.env` file in the root and add:
```
DB_NAME
DB_PASS
```

### 4️⃣ Start the Backend Server
```sh
npm start
```
🚀 The backend will run at **`http://localhost:5000`**
